# ToEE — Phase 2: Named & Tribalized Monster Groups (aligned per-group format)

Reformatted to match the Phandalin `monsters_phase2_descriptions.md` convention:
one `## Tribe N —` section per tribe, one `### N.M` subsection per consolidated group,
with `Monster type / Source / Verbatim count / CR (individual) / Named as / Description / Named-leader`.

Source of truth for group structure: `monsters_phase1_scan.md`. Collective band names and
coined individual flavor originally authored in the rich prose version (now backed up as
`monsters_phase2_descriptions.rich.bak`). Module-named NPCs (Zuggtmoy, Iuz, Hedrack, Lareth,
the Four High Priests, Rannos Davl, Gremag, Zert, Kobort, Lubash, Grank, etc.) are preserved
verbatim and flagged `(module-named — EXCLUDED)`; they are never renamed.
