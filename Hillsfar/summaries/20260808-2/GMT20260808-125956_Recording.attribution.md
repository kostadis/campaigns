**`transcript_provenance.py` did not catch it.** `is_transcript()` accepts a `.txt` only if

invisible to the scan. That is the same blind spot the Aug 10 chapter-23 `.txt` hit. Worth
fixing in the tool.

This file is also the **timestamped** version's only surviving trace: the morning run used
`session_2026_08_08_chapter_22_..._transcript.vtt` (222.1 min = 93.4 AM + 128.6 PM) as its
text layer. That `.vtt` is no longer anywhere in the tree — only this `.txt`, with the
timestamps stripped. It therefore cannot drive a time-based join and was used as a quality
reference only.

## Phase 2 — diarization, and why `num_speakers=3` is wrong here

`pyannote/speaker-diarization-community-1`, `device_used=cuda`, audio 7718.0 s, 70.5 min of
speech.

**The skill says to pass `num_speakers` because you know it. On this recording that produces
a broken clustering.** Four runs:

| run | split | verdict |
|---|---|---|
| `num_speakers=3` | 52.5 / 44.1 / **3.4** | degenerate |
| **free estimation (no `num_speakers`)** | **identical — 3 speakers, 52.5 / 44.1 / 3.4** | degenerate |
| **`num_speakers=4`** ← shipped | **37.9 / 27.8 / 23.9 / 10.3** | best available |
| `num_speakers=5` | 29.4 / 23.8 / 19.9 / 16.7 / 10.2 | over-clustered |

Largest cluster is under 70% in every run, so the skill's **collapse** test passes
throughout. This is a different failure: a **merge**.

Three independent lines of evidence that `n=3` merged the two players:

1. **The third cluster is not a person.** 2.4 min / 244 words, and the words are
   "Alright." "Alright, cool." "Great." "Okay." "Right." — pure acknowledgement filler.
   Two of three people had to share the remaining two slots.

2. **The fourth cut splits the big cluster nearly in half, not into a sliver.** Time overlap,
   n=3 rows × n=4 columns, % of row:

   ```
              →S00     →S01     →S02     →S03      min
   S02 (n=3)  7.6%     1.9%    42.9%    47.6%     37.3   ← splits ~50/50
   S01 (n=3)  8.8%    83.6%     1.5%     6.1%     31.4   ← stays put (the GM)
   S00 (n=3) 71.6%     0.6%    23.6%     4.3%      2.5   ← the filler fragment
   ```

   Shaving a register off a speaker looks like 90/10. This is 43/48.

3. **n=4 reproduces the morning recording's validated shape.** Same three people, same room,
   same mic, two hours earlier:

   | | GM | player | player |
   |---|---|---|---|
   | Aug 8 **AM**, n=3 (confirmed) | 48.4% | 28.1% | 23.5% |
   | Aug 8 **PM**, n=4 (S01 + S00 fragment) | 37.9 + 10.3 = **48.2%** | **27.8%** | **23.9%** |

`n=5` was run as the stability check and splits the **GM** cluster 61.9 / 34.1 — the fifth
cut starts fragmenting a real speaker rather than isolating more junk. **4 is the ceiling.**

**`SPEAKER_00` (10.3%, 7.3 min) is a fragment, not a person.** It draws 8.8% from the GM's
n=3 cluster and 7.6% from the players' — it cuts across everyone. Its cues should be treated
as unattributed, and that is recorded in the VTT's NOTE header.

Both diarization files are kept: `.diarization.json` is the shipped n=4 run;
`.diarization.n3.json` is the n=3 run, so the join can be redone either way without GPU time.

Confusion matrix, words, Descript (rows) × pyannote n=4 (cols):

```
Speaker 2               551         1629         2665         3490    7% / 20% / 32% / 42%   <- no clear home
Speaker 3               425         4314          812         1081    6% / 65% / 12% / 16%
Speaker 4               153            0           81          168   402 words — spurious split
Speaker                 181           14           60           57   312 words — spurious split
```

**Word-level agreement: 65.0%** (n=3 against the same text scores 74.3%; Aug 8 AM: 81.3%;
Aug 10: 72.0%; Phandalin ch04: 82.2%).

**Do not read 65.0% as "the diarization failed."** Descript put **95.5% of words into two
clusters for three people** (53.2% / 42.3%, plus 714 words of fragments) — it made the *same
merge* pyannote made at n=3. Agreement with a merged reference rewards reproducing the merge:
that is precisely why n=3 scores 74.3% and the correct n=4 scores 65.0%.

Descript's `Speaker 2` (8335 words) spreads 7 / 20 / 32 / 42 across the four clusters and
fails the concentration test. That row **is** the merged pair. Its 32/42 split lines up with
the two player clusters pyannote separated.

The independent checks that do apply — largest cluster < 70%, the n=3→n=4 split geometry, and
the match to the morning recording's confirmed shape — all pass.

## What is undecided, and the known limits

1. **The mapping itself.** Skill checkpoint 3. `SPEAKER_02` in particular rests on
   elimination, not evidence — the name "Daein" occurs **zero times** in the text layer.

2. **`SPEAKER_00` is 10.3% of speech with no owner.** Larger than the usual 1–3% fragment.
   7.3 minutes of cues carry a label that is not a person.

3. **Crosstalk is the binding constraint, worse here than on Aug 10.** 3107 diarization turns
   (mean 1.36 s) against 1016 text cues; **543 cues (53%) span more than one turn**. Aug 10
   was 46%. Rapid exchanges collapse onto one label by construction.

4. **~40 cues still diverge sharply from the Zoom source** and were left alone (see Phase 1).
   Some are Whisper fabrications; some are Whisper being right where Zoom was wrong. Reading
   them one by one is a human job.

5. **Cue text still carries Zoom's `Kostadis Roussos:` prefix** inside the body, inherited
   from the scaffold. Zoom labelled all 1147 cues that way; it means nothing and should
   probably be stripped before downstream use.

6. **The whole-day chapter-22 `.txt` has no timestamps.** The timestamped version used by the
   morning run is gone from the tree. If it can be recovered, its second half is better text
   than anything here.
